# Figures

draw.io sources (`.drawio`, open with diagrams.net) and the PNG export of each, in Vietnamese and English (`_en`).

| Figure | What it shows |
|---|---|
| `hinh_pipeline_he_thong` | Flow of the system in the style of the CodeSIM/MapCoder figures: question → router → catalogue of prompts → solver (zero-shot or ReAct + Calculator) → answer |
| `hinh_kien_truc_he_thong` | The same system as a poster-style architecture figure ("KIẾN TRÚC HỆ THỐNG") |

Both were drawn as a first version and are meant to be refined before they go into a paper. The figures of the Complex Numbers paper
are in the repository `react-calculator-complex-numbers` (also mirrored under `so_phuc/`).
