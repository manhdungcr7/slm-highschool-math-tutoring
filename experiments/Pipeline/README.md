# Pipeline notebook

`KLTN_Pipeline_GiaSu_100cau.ipynb` runs the whole tutor in four steps:

1. **Router:** the question goes to Qwen3-0.6B + LoRA, which predicts its dạng.
2. **Prompt:** the prompt of that dạng is loaded.
3. **Solver:** Qwen3-4B solves the question with that prompt.
4. **Answer:** the chosen answer is extracted.

The notebook is generated by `scripts/pipeline/build_pipeline_notebook.py`, and its cells are in
`scripts/pipeline/pipeline_cells.py`. The builder writes `data/pipeline_bundle/pipeline_units.json`, which holds the
code of the final experiment notebook of every dạng, copied verbatim. The pipeline gives that code the routed
questions, one shared tokenizer and one shared vLLM engine. The md5 of every prompt is checked against the original
before solving.

Rebuild: `python scripts/pipeline/build_pipeline_notebook.py` (router: `models/router_lora`; question set: see
`data/results/pipeline_realworld/`). Check without GPU: `python scripts/pipeline/dry_run_pipeline.py`. Analyse a run:
`python scripts/pipeline/analyze_pipeline_errors.py`.

| Group | Final notebook used |
|---|---|
| 32 Mũ-Logarit ReAct dạng | The latest of `KLTN_G01`-`G10`, `H01`-`H05`, `R01` (D68), `R04` (D40) and the D79 notebook in `experiments/ReAct-Calculator/` |
| 23 Số phức ReAct dạng | The 15 single-type notebooks, plus `KLTN_Nhom1` (D04, D14, D28, D32, D33) and `KLTN_Nhom2` (D40, D42, D49) in `so_phuc/experiments/Qwen3-4B/` |
| 56 Mũ-Logarit zero-shot dạng | `experiments/Qwen3-4B/KLTN_mulogarit_zeroshot_full90_Qwen3-4B.ipynb` (`presence_penalty=1.2`) |
| 31 Số phức zero-shot dạng (including D34, which is not scored) | `experiments/Qwen3-4B/qwen_eval_kaggle_sophuc_zeroshot.ipynb` (no presence penalty) |

`data/pipeline_bundle/bang_dang_prompt.csv` lists, for each of the 142 dạng, its solving method, source notebook,
tool-call limit and prompt md5. Results are in [`data/results/pipeline_realworld/`](../../data/results/pipeline_realworld/).
