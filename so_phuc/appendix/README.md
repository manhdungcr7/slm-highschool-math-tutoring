# Appendix: 53 Complex Numbers Problem Types

This directory contains the appendix for the paper submitted to SoICT 2026.
It lists the 53 Complex Numbers problem types, coded D01 through D54 without
D34, used in the study. D34 was removed because its answer key counted
$z = 0$ as purely imaginary. The result tables in the paper show only these codes.

- The complete English list is available in the
  [repository README](../README.md#appendix-53-problem-types-complex-numbers).
- The machine-readable bilingual list is available in
  [`problem_types_53.csv`](problem_types_53.csv).
